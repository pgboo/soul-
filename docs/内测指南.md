## 一、怎么开始

### 1. 打开地址

**👉 访问地址：https://mentioned-radical-converter-algorithm.trycloudflare.com**

> ⚠️ 这个地址是**临时的**（免费快速隧道）。我的电脑关机、网络切换或隧道重启，Cloudflare 都可能回收域名并换一个新的。如果打不开，请在群里问我要最新地址。
>
> 💡 **用 App 的同学注意**：如果 App 里提示「连不上服务器」或 network error，
> **不用重新下载安装包** —— 在登录页点最下方「连不上服务器？点这里改地址」，
> 把我发的新地址粘进去、点「保存并重试」即可。

- 手机上直接点开这个链接就能用（推荐，这个 App 是为手机设计的）
- 电脑上也能开，但请按 `F12` 打开开发者工具 → 点左上角的手机图标切成手机视图
- 建议用**微信内置浏览器之外的**浏览器打开（Safari / Chrome / 夸克 / Edge 都行）

> **也可以装成 App（仅安卓手机）**
> 👉 APK 文件：`dist-apk/Soul社交-内测版-v1.3.apk`（3.3MB）
> 下载后用**浏览器**打开安装包（微信里点不开，会被拦），安装时允许「安装未知来源应用」。
> iPhone 装不了 APK，请直接用上面的网页链接。
> 注意：App 只是个外壳，数据仍在测试服务器上，**必须联网**才能用；服务器关了就打不开。
> 另外 App 里的服务器地址是可以在应用内修改的（见上方说明），地址变了不必重装。

### 2. 登录

- **手机号：随便填一个 11 位数字**（比如 `13800000001`，不用是你真实的号）
- **验证码：固定 `123456`**

> 这是内测环境，不接真实短信，所以任意手机号都能登录。新号码会自动注册。
> ⚠️ 请**不要填你真实的手机号**，避免个人信息进测试库。
> ⚠️ 同一个手机号 60 秒内只能获取一次验证码，如果提示"发送过于频繁"，等一分钟再试。

### 3. 第一次进来会走一遍初始化

完善资料 → 选标签 → 做灵魂测试 → 进主界面。**这一整段就是重点测试对象**，请慢慢走，有任何卡顿/报错/看不懂的地方都记下来。

## 二、请按这个清单测（重要）

不要只是"随便点点"，麻烦按下面的任务逐条走一遍，**每条走完都记一下结果**。

### 任务 1 · 注册与初始化
1. 用任意手机号登录
2. 完善资料：**重点试「选择城市」和「上传头像」**
   - 城市选择弹框能不能正常弹出、能不能选中、选完有没有回填
   - 头像能不能上传成功、上传后有没有显示出来
3. 选标签：至少选 3 个（上限 10 个）
4. 做灵魂测试，看结果页

### 任务 2 · 发一条瞬间（重点）
1. 进「广场」→ 点右下角的 `＋`
2. 写一句话，**配 1~2 张图**
3. 点「# 话题」→ **试试自己拟一个话题**（输入框里打字 → 点创建）
4. 发布 → 回到广场，**确认能不能看到自己刚发的那条**

### 任务 3 · 广场互动
1. 在广场刷一刷，看看别人的动态
2. 点赞、取消点赞、收藏
3. 点进一条动态看详情，**发一条评论**，再回复别人的评论
4. 切换「推荐 / 最新 / 同城」三个频道，看有没有报错

### 任务 4 · 找人聊天
1. 进「匹配」，看推荐的用户
2. 点进某个人主页，看看资料展示
3. 发起聊天，发几条消息，退出再进来看记录还在不在
4. 试试「不感兴趣」、拉黑、取消拉黑

### 任务 5 · 我的页面
1. 进「我的」，看资料
2. 点「编辑资料」，**改一下城市和头像，保存后看有没有生效**
3. 看看「我的收藏」「隐私设置」「黑名单」

## 三、发现问题怎么反馈

**统一填这张表 👉 `{{反馈收集表链接}}`**

每条问题请尽量写清楚这 5 项，缺一项我就很难复现：

| 要写什么 | 例子 |
|---|---|
| **机型 / 浏览器** | iPhone 14 / Safari；小米 13 / Chrome |
| **在哪个页面** | 广场 → 发瞬间 |
| **怎么操作的** | 点右下角＋ → 输入文字 → 点「# 话题」→ 输入"周末计划"→ 点创建 |
| **你期望的结果** | 话题创建成功并被选中 |
| **实际发生了什么** | 点了创建没反应，弹框直接关了 |
| **截图 / 录屏** | 有截图最好，比文字描述有用 10 倍 |

> 如果实在懒得填表，**直接在群里说 + 甩截图**也行，但请务必说清楚"在哪个页面、点了什么"。

## 四、也欢迎提需求

除了找 bug，更欢迎你说：

- **哪里用起来别扭**：比如"发动态要滑好几屏才能点到发布按钮"
- **缺了什么**：比如"希望能看到谁给我点了赞"
- **觉得多余的地方**：比如"这个步骤完全没必要"
- **整体印象**：你会不会想用第二次？为什么？

这些"不好用"的反馈，比"打不开"的 bug 更有价值。
